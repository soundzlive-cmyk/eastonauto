# Easton Auto Body website

Static HTML/CSS/JS site, no build step needed. Open `index.html` in a browser, or upload the whole folder to any static host (e.g. GitHub Pages).

Pages: index, about, services (#collision #painting #dent #custom), work, insurance, contact, estimate.
